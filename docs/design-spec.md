# Notch Vinyl 디자인 명세

상태: 브레인스토밍을 바탕으로 한 1차 디자인 기준

## 1. 컨셉

**맥북 노치 속에 작은 레코드가 숨어 있다.**

노치 아래로 드러난 LP가 제품의 대표 이미지다. 사용자는 화면 속 레코드를 당겨 꺼내고 직접 돌리면서 음악을 탐색한다. 로고와 앱 화면 모두 이 하나의 장면을 공유한다.

감성의 기준은 **작고 정교한 아날로그 음악 도구**다. 검은 바이닐의 은은한 반사, 따뜻한 종이 레이블, 손끝에 반응하는 움직임으로 표현한다. 오래된 종이의 얼룩이나 과한 빈티지 장식보다, 잘 관리된 레코드 한 장의 느낌을 지향한다.

## 2. 핵심 조형

### 기본 심볼

- 위쪽에는 가로로 긴 검은 노치, 아래쪽에는 노치에서 절반쯤 드러난 원형 레코드를 배치한다.
- 레코드의 중심은 노치의 아래 경계선에 놓는다. 노치가 레코드의 위쪽 반원을 가린다.
- 노치와 레코드는 하나의 연결된 검은 실루엣으로 읽혀야 한다.
- 중앙 레이블도 아래쪽 반원만 보인다. 가운데 작은 스핀들 구멍은 경계에서 살짝 드러난다.
- 바이닐 홈과 표면 반사는 원형 구조를 설명할 만큼만 넣는다.
- 기본 심볼에는 글자, 음표, 재생 버튼, 톤암을 넣지 않는다.

### 시안 제작용 비율

아래 수치는 첫 시안을 위한 출발점이며, 작은 크기에서의 판독성을 보고 조정한다.

| 요소 | 기준 |
| --- | --- |
| 레코드 지름 | D |
| 노치 너비 | 약 1.35D |
| 노치 높이 | 약 0.22D |
| 노치 아래 모서리 반경 | 약 0.07D |
| 레이블 지름 | 약 0.34D |
| 스핀들 구멍 지름 | 약 0.035D |
| 심볼 주위 최소 여백 | 0.20D |

노치는 캡슐보다 화면 상단에서 내려온 하우징에 가깝게 그린다. 위 모서리는 절제하고 아래 모서리를 부드럽게 처리한다. 실제 앱에서는 기기의 물리 노치 형상을 따른다.

## 3. 색상

검은 몸체와 따뜻한 레이블을 기본 조합으로 사용한다.

| 역할 | 색상 | 용도 |
| --- | --- | --- |
| Hardware Black | `#000000` | 노치, 연결부 |
| Vinyl Black | `#0A0A0B` | 레코드 바탕 |
| Paper Cream | `#EBE0C9` | 브랜드 기본 레이블, 밝은 배경 |
| Label Ink | `#1C1A17` | 종이 위 글자와 세부 인쇄 |
| Rust | `#B3543D` | 레이블의 작은 포인트, 강조 |
| Warm Gray | `#928B80` | 보조 텍스트 |

기본 로고는 크림색 레이블을 사용한다. 러스트는 작은 인쇄 띠나 점처럼 제한적으로 사용하며, 두 색의 비중이 경쟁하지 않도록 한다. 앱에서는 앨범 아트가 레이블을 대체할 수 있다.

## 4. 재질과 빛

### 바이닐

- 검정에 가까운 표면에 가느다란 동심원 홈을 넣는다.
- 넓고 약한 방향성 반사로 곡면과 회전을 느끼게 한다.
- 홈은 작은 아이콘에서 생략할 수 있다. 축소했을 때 줄무늬나 모아레가 보이면 줄인다.
- 금속처럼 밝은 테두리나 무지개빛 반사는 사용하지 않는다.

### 종이 레이블

- 따뜻한 크림 바탕에 미세한 종이 결을 사용한다.
- 인쇄는 선명하되 화면 전체를 거칠게 만드는 노이즈는 피한다.
- 찢어진 가장자리, 때, 스크래치, 인위적인 인쇄 어긋남은 기본 표현에 포함하지 않는다.

### 깊이

- 노치 아래에 짧고 부드러운 접촉 그림자를 두어 레코드가 안에서 나오는 관계를 보여준다.
- 레코드 가장자리는 얇은 두께만 암시한다.
- 빛과 그림자보다 실루엣이 먼저 읽혀야 한다.

## 5. 로고와 앱 아이콘

### 로고 구성

- **기본 심볼:** 노치와 반쯤 나온 레코드.
- **워드마크 조합:** 심볼 옆에 `Notch Vinyl` 표기. 이름의 공식 철자는 Vinyl로 통일한다.
- **단색 심볼:** 질감과 그림자를 제거해도 노치와 레코드의 관계가 남도록 제작한다.
- **메뉴 바 심볼:** 작은 크기에 맞춰 레이블과 홈을 단순화한 별도 광학 보정본을 사용한다.

워드마크는 부드러운 인상의 절제된 서체를 출발점으로 한다. 장식적인 복고 서체는 피하고, 구체적인 서체는 시안에서 비교해 결정한다.

### 앱 아이콘

- 따뜻한 크림색 바탕 위에 기본 심볼을 배치한다.
- 심볼 위쪽에 여백을 남겨 노치와 레코드가 아이콘 경계에 붙지 않게 한다.
- 광학적으로 중앙에 배치하고, 반원 아래쪽에 충분한 여유를 둔다.
- 바탕은 은은한 종이 또는 무광 재질로 표현한다. 강한 입체 테두리와 광택은 피한다.
- macOS용 최종 외곽 마스크와 패키징은 실제 적용 환경에 맞춰 검증한다.

### 축소 기준

| 크기 | 남길 요소 |
| --- | --- |
| 512–1024px | 종이 결, 얇은 홈, 부드러운 반사와 접촉 그림자 |
| 64–256px | 주요 홈과 반사, 단순한 레이블 |
| 32px | 노치·레코드·레이블의 큰 형태 |
| 16px | 단색 실루엣과 필요한 최소 음각 |

작은 크기에서는 큰 원본을 그대로 축소하기보다 선 두께와 레이블 크기를 보정한다.

## 6. 앱 화면 적용

### 기본 상태

- 노치의 검은 형태를 유지한다.
- 커서가 접근하면 레코드 가장자리가 아주 조금 드러나 당길 수 있음을 암시한다.
- 시각적 장식은 노치 주변의 좁은 영역에 집중한다.

### 레코드를 꺼낸 상태

- 로고의 장면과 동일하게, 노치 아래로 레코드의 아래쪽 반원이 보인다.
- 실제 레코드는 완전한 원으로 렌더링하고 위쪽 부분을 노치가 가린다.
- 앨범 아트가 있으면 중앙의 원형 레이블로 사용한다.
- 앨범 아트가 없으면 크림 종이 레이블과 트랙 정보 기반 인쇄를 사용한다.
- 곡 정보와 시간 표시는 레코드 밖의 고정된 위치에서 읽을 수 있게 한다. 회전하는 레이블의 글자에만 정보를 의존하지 않는다.
- 시간과 탐색 변화량은 자릿수가 흔들리지 않는 숫자로 표시한다.

### 정보의 우선순위

1. 레코드와 손의 조작 관계
2. 현재 탐색 위치와 변화량
3. 곡 제목과 아티스트
4. 연결 상태와 보조 안내

보조 정보는 필요한 상태에서 나타나며, 레코드가 주인공으로 남도록 크기와 대비를 조절한다.

## 7. 움직임

- **당기기:** 노치 속 물체를 꺼내는 약한 저항감으로 시작한다.
- **펼쳐짐:** 임계점을 넘으면 자석의 걸림을 넘듯 명확하게 자리를 잡는다.
- **돌리기:** 손의 이동에 회전과 탐색이 즉시 반응한다.
- **재생:** 수동 회전에서 일정한 자동 회전으로 자연스럽게 이어진다.
- **넣기:** 위쪽으로 끌려 들어가며 노치의 검은 형태로 정리된다.
- **취소:** 짧은 반응과 햅틱으로 탐색 취소를 전달한다.

움직임은 짧고 절제한다. 반복해서 통통 튀는 연출이나 긴 관성은 피한다. 기존 조작 방식과 상태 전이는 유지하고, 이 명세에서는 표현의 질감을 정한다. 동작 줄이기 설정에서는 이동과 반동을 최소화하되 상태 변화는 명확히 전달한다.

## 8. 시안 제작 범위

첫 시안에서는 동일한 조형으로 아래 세 가지 레이블 표현을 비교한다.

1. **Cream Label:** 크림 레이블과 작은 러스트 포인트. 기본 후보.
2. **Rust Label:** 러스트 레이블과 크림 인쇄. 더 강한 인상.
3. **Quiet Mono:** 색을 절제한 단색 레이블. 실루엣과 재질 확인용.

각 후보는 큰 앱 아이콘, 32px 아이콘, 단색 메뉴 바 심볼을 함께 놓고 비교한다. 앱 적용 목업은 기본 상태와 펼친 상태를 한 쌍으로 만든다.

## 9. 검토 기준

- 이름을 읽기 전에도 노치 아래로 나온 레코드가 보이는가?
- 노치와 레코드가 하나의 검은 물체처럼 자연스럽게 연결되는가?
- 32px에서도 레이블과 레코드가 구분되는가?
- 단색에서도 형태의 개성이 남는가?
- 아날로그 감성이 색·재질·움직임에서 일관되게 느껴지는가?
- 밝고 어두운 배경 모두에서 실루엣이 유지되는가?
- 실제 앱의 반원 노출 구조와 로고가 같은 장면으로 읽히는가?

## 10. 후속 결정

시안 비교 후 레이블의 최종 색상, 워드마크 서체, 앱 아이콘 바탕의 질감 강도를 결정한다. 이 문서는 시각 디자인 기준이며, 로고 파일 제작이나 앱 코드 변경은 아직 포함하지 않는다.
