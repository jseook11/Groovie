# Umak 인터랙션 가이드

노치에 숨은 레코드를 손으로 다루는 방법을 정리한 문서입니다.
빠르게 훑을 수 있는 표에서 시작해, 각 제스처의 의도와 경계 동작까지 설명합니다.

![제스처 맵](assets/gestures.svg)

## 1. 한눈에 보기

| 하고 싶은 것 | 마우스 | 트랙패드 |
| --- | --- | --- |
| 노치 영역 깨우기 | 상단 중앙으로 포인터 이동 | 상단 중앙으로 포인터 이동 |
| 재생 / 일시정지 | 닫힌 노치 또는 고정된 레코드의 중앙 레이블 클릭 | 왼쪽과 같음 |
| 곡 넘기기 | — | 노치 또는 고정된 레이블 위에서 가로 두 손가락 스와이프 |
| 음악 앱 부르기 | — | 노치 위에서 위로 두 손가락 스와이프 |
| 레코드 꺼내기 | 노치에서 아래로 드래그 | 노치 위에서 아래로 스크롤 |
| 재생 위치 탐색 | 레코드를 잡고 좌우로 드래그 | 바이닐 위에서 좌우 스크롤 |
| 레코드 고정 | 240pt 더 당기기, 또는 놓은 뒤 1초 안에 다시 잡기 | 계속 아래로 스크롤, 또는 0.8초 멈췄다가 다시 아래로 |
| 레코드 닫기 | 바이닐 클릭, 위로 드래그 | 위로 스크롤 |
| 바탕화면으로 복사 | 완전히 열린 레코드에서 ⌥+드래그 | ⌥+드래그 |
| 앨범 아트 배치 | 완전히 열린 레코드에서 ⌥+클릭 | ⌥+클릭 |
| 바탕화면 사본 이동 | 사본에서 ⌥+드래그 | ⌥+드래그 |
| 바탕화면 사본 형태 전환 | 사본에서 ⌥+클릭 (열린 슬리브 → 닫힌 슬리브 → 레코드 판) | ⌥+클릭 |
| 바탕화면 사본 삭제 | 사본 중심을 상단 노치 영역으로 드래그 | 같음 |
| 탐색 취소 | 1초 안에 좌우로 4번 흔들기 | — |

> 트랙패드의 가로 스와이프는 **오른쪽 = 다음 곡, 왼쪽 = 이전 곡**입니다.
> 레코드를 돌릴 때는 반대로 **오른쪽 = 되감기, 왼쪽 = 앞으로 감기**입니다.

## 2. 기본 구조

Umak에는 컨트롤이 하나뿐입니다. 노치 속에서 반쯤 나온 **레코드** 한 장입니다.

- **노치** — 레코드가 들어 있는 슬리브입니다. 맥북 카메라 하우징이거나, 노치가 없는
  화면에서는 화면 상단 중앙의 179pt 영역입니다.
- **레코드** — 원판 전체를 그리지만 위쪽 반은 노치 뒤에 가려집니다. 그래서 항상 아래쪽
  반원만 보이고, 중심은 노치의 아래 경계선에 놓입니다.
- **레이블** — 레코드 가운데의 종이 라벨입니다. 고정된 상태에서 재생/일시정지 버튼이
  됩니다. 앨범 아트가 있으면 아트, 없으면 트랙에서 뽑은 색으로 인쇄됩니다.
- **고정(pin)** — 레코드를 꺼낸 뒤 놓아도 노치로 돌아가지 않고 밖에 남겨 둔 상태입니다.
- **닫힘** — 레코드가 노치 안으로 완전히 들어간 상태입니다.

## 3. 노치에서 바로

레코드를 꺼내지 않아도 노치 영역에서 바로 할 수 있는 일이 있습니다.

![노치 영역의 제스처](assets/notch-gestures.svg)

### 한 번 클릭 = 재생 / 일시정지

노치 영역을 클릭하면 현재 곡의 재생 상태를 토글합니다. 레코드가 닫혀 있어도 동작하며,
레코드의 회전과 메뉴 헤더의 상태는 클릭 즉시 바뀝니다. Music의 응답을 기다리지 않습니다.

재생할 트랙이 없거나 Music이 실행 중이 아니면 클릭은 Music을 앞으로 가져옵니다.
그 상태에서는 사용자가 Music에서 곡을 고르면 됩니다.

### 가로 두 손가락 스와이프 = 이전 / 다음 곡

노치 위에서 두 손가락을 가로로 스와이프합니다.

- **오른쪽** → 다음 곡
- **왼쪽** → 이전 곡

오작동을 막기 위해 다음 조건을 모두 만족해야 합니다.

- 가로 이동이 **90pt 이상**
- 세로 이동보다 **1.5배 이상** 가로 우세
- 제스처가 시작될 때 축이 가로로 고정됨
- 한 제스처당 **한 번만** 넘김

세로로 시작한 스크롤은 도중에 방향이 흔들려도 곡을 넘기지 않습니다. 곡이 바뀌면
제목·아트워크·진행 바는 Music이 새 트랙을 보고한 뒤 갱신됩니다.

### 아래로 스크롤 = 레코드 꺼내기

노치 위에서 두 손가락으로 아래로 스크롤하면 레코드가 나옵니다. 중간 지점에서 자석처럼
완전히 펴지고 가벼운 햅틱이 울립니다.

### 위로 스와이프 = 음악 앱 부르기

트랙이 있고 레코드가 닫혀 있을 때 노치 위에서 두 손가락으로 **위로** 스와이프하면 활성
플레이어(Music 또는 Spotify)가 앞으로 나옵니다. 마음에 들지 않는 곡이 이어질 때 커서를
Dock까지 내리지 않고 바로 앱에서 곡을 고르기 위한 제스처입니다.

- 레코드를 닫는 위로 스크롤(고정된 레코드)과는 상태로 구분됩니다. 레코드가 열려 있으면
  이 제스처는 동작하지 않습니다.
- 세로 이동이 가로 이동의 **1.5배 이상**이어야 하고, 누적 이동이 **90pt**를 넘어야
  발동합니다.
- **제스처당 한 번만** 발동하며, 관성 스크롤로는 발동하지 않습니다.
- 한 번 정해진 축은 제스처가 끝날 때까지 유지됩니다. 위로 시작한 스와이프가 도중에
  아래로 바뀌어도 레코드가 열리지 않습니다.
- 플레이어가 ⌘H로 숨겨져 있거나 ⌘M으로 최소화되어 있으면 다시 나타나고, 창을 닫아 둔
  상태에서도 창이 돌아옵니다. 앱이 꺼져 있으면 실행합니다.
- 트랙이 없거나 플레이어가 실행 중이 아니면 이 판정 대신 기존 "플레이어 앞으로 가져오기"
  경로가 처리합니다. 스크롤 방향과 관계없이 한 제스처당 한 번 플레이어가 앞으로 나오고,
  플레이어가 꺼져 있으면 실행합니다.

### 첫 실행 안내

노치가 없는 화면에서는 상단 중앙에 아무 형체도 없기 때문에, 앱을 처음 실행하면 노치
영역 아래에 작은 안내 카드가 나타납니다.

- **클릭** — 재생 / 일시정지
- **두 손가락 스와이프** — 이전 / 다음 곡
- **아래로 당기기** — 레코드 꺼내기
- **위로 스와이프** — 음악 앱 부르기

카드는 약 7.5초 뒤 사라지며, 마우스 이벤트를 전혀 받지 않아 조작을 가로막지 않습니다.
노치 영역에서 첫 제스처가 시작되면 즉시 사라집니다. 한 번 본 뒤에는 다시 뜨지 않지만,
상태 메뉴의 **제스처 안내 보기**로 언제든 다시 볼 수 있습니다.

> 안내 카드는 자동으로는 노치 없는 화면에서만 나타납니다. 노치가 있는 맥에서도 메뉴의
> **제스처 안내 보기**를 사용하면 같은 카드를 볼 수 있습니다.

## 4. 레코드 꺼내기

레코드는 노치 안에서 시작한 **아래 방향 수직 드래그**로만 꺼냅니다.

| 이동 거리 | 동작 |
| ---: | --- |
| 8pt | 당김이 시작됩니다. |
| 40pt | 자석이 작동해 레코드가 완전히 나옵니다. 가벼운 햅틱. |
| 80pt | 포인터 이동이 완전히 펼쳐진 상태에 대응합니다. |
| 40pt 미만에서 놓음 | 스프링으로 다시 들어갑니다. |

레코드가 나오면 중심이 노치의 아래 경계선에 정확히 놓입니다. 이 상태에서 세로로는 더
움직이지 않고, 좌우 이동만 재생 위치를 바꿉니다.

처음 움직임이 수평이거나 위쪽이면 당기기로 인식하지 않습니다. 노치 영역에서 시작하지
않은 드래그도 무시합니다.

## 5. 재생 위치 탐색

레코드를 잡고 좌우로 움직이면 재생 위치가 바뀝니다.

- **오른쪽으로 돌리면 되감기**
- **왼쪽으로 돌리면 앞으로 감기**
- 천천히 움직이면 정밀하게, 빠르게 움직이면 같은 거리에서 더 크게 탐색합니다.
- 트랙의 시작(0:00)과 끝에 닿으면 그 이상 움직이지 않고 레코드도 더 돌지 않습니다.
- 탐색 중에는 레코드 아래에 `−2.7s`, `+1:03.4` 같은 오프셋이 표시됩니다.

가로 이동에는 데드존이 있습니다. 레코드가 아직 고정되지 않았을 때는 **90pt**, 고정된
뒤에는 마우스 **4pt** / 스크롤 **30pt**입니다. 고정 전 데드존이 큰 이유는 세로로 당기는
동안의 좌우 흔들림이 탐색으로 새지 않게 하기 위해서입니다.

## 6. 레코드 고정

레코드를 꺼낸 것만으로는 고정이 아닙니다. 손을 놓으면 잠시 뒤 노치로 돌아갑니다.
다음 중 하나를 하면 그 자리에 고정됩니다.

1. **240pt 더 당기기** — 레코드가 나온 지점부터 추가로 아래로 당깁니다. 빠르게 당기면
   속도 계수가 붙어 최대 **3.2배**까지 빨리 채워집니다.
2. **놓은 뒤 1초 안에 다시 잡기** — 마우스로 살짝 놓았다가 1초 안에 다시 끌면 고정됩니다.
3. **트랙패드로 계속 스크롤하기** — 스냅된 뒤 계속 아래로 스크롤하거나, 0.8초 이상 멈췄다가
   다시 아래로 스크롤합니다. 스크롤은 480pt를 채워야 하며 속도 보정이 붙습니다.

레코드 아래에는 반투명 게이지가 표시됩니다. 게이지는 레코드가 완전히 나온 순간 0에서
시작하고, 추가로 당길수록 채워집니다. 가득 차면 자동으로 고정되고 햅틱이 울립니다.

고정 중에는 가로 데드존이 90pt로 넓어집니다. 세로로 당기는 동안 좌우로 흔들려도 재생
위치가 바뀌지 않습니다. 반대로 가로 이동은 고정 사유가 되지 않습니다.

고정하지 않고 놓으면 마우스는 약 1초, 스크롤은 약 1.4초 뒤 스프링으로 들어갑니다.

## 7. 고정된 레코드

레코드가 고정되면 밖에 남은 채로 다음 조작을 할 수 있습니다.

### 중앙 레이블 클릭 = 재생 / 일시정지

중앙 레이블을 클릭하면 재생/일시정지가 토글되고 레코드는 그대로 남습니다.

- 레이블은 중심이 노치 경계에 있어 아래쪽 반원만 보입니다. 그래서 히트 영역은 레이블
  반경 30pt보다 12pt 넓은 **42pt**입니다.
- 클릭 결과는 즉시 반영됩니다. Music의 상태 확인이 늦게 도착해도 최대 2초 동안은
  요청한 상태를 유지하므로, 레코드가 잠깐 되돌아가지 않습니다.
- 레이블 바깥의 바이닐을 클릭하면 재생 상태는 그대로 두고 레코드가 닫힙니다.

### 레이블 호버 = 다음 동작 미리보기

고정된 레코드의 레이블 위에 포인터를 올리면 레이블이 조금 어두워지고, 현재 상태에 따라
일시정지(❚❚) 또는 재생(▶) 기호가 연하게 나타납니다. 포인터는 포인팅 핸드로 바뀝니다.
바이닐 자체는 호버에 반응하지 않아, 포인터가 판을 지나갈 때 화면이 흔들리지 않습니다.

### 레이블 위 가로 스와이프 = 곡 넘기기

고정된 레코드에서는 **레이블 위에서 시작한** 가로 스와이프만 곡을 넘깁니다.
바이닐 위에서 시작한 스와이프는 기존처럼 탐색입니다. 레이블에서 곡을 넘기려면 노치와
같은 90pt 임계값과 1.5배 가로 우세 조건을 만족해야 합니다.

### 닫기

- 바이닐 클릭
- 위로 드래그
- 위로 스크롤

고정을 풀고 레코드가 노치로 돌아갑니다. 닫을 때의 재생 위치가 확정되고, 원래 일시정지
상태였다면 닫은 뒤에도 일시정지가 유지됩니다.

### 흔들어서 취소

레코드를 잡은 채 1초 안에 좌우로 4번 이상 방향을 바꾸면(각 8pt 이상) 이번 탐색을
취소하고 잡기 직전 위치로 돌아갑니다. 가벼운 햅틱이 울립니다. 고정된 상태에서 취소하면
레코드는 밖에 남습니다.

### 바탕화면으로 복사·배치

레코드가 완전히 열려 있으면(고정 여부와 무관) 그 레코드 위에서 Option(⌥)을 누른 채
조작해 장식용 사본을 만들 수 있습니다. 원본 레코드와 재생 상태는 바뀌지 않습니다.

- **⌥+드래그**: 레코드 판 사본이 포인터를 따라 나옵니다. 바탕화면에 놓으면 그 자리에
  정적 이미지로 남습니다.
- **⌥+단발 클릭**: 같은 곡이 앨범 아트 슬리브(커버에서 레코드가 살짝 나온 형태)로
  바탕화면에 놓입니다.
- 제스처가 진행되는 동안 원본은 열린 상태로 유지됩니다. 고정되지 않은 레코드는 제스처가
  끝난 뒤 원래의 1초 확인 창을 거쳐 닫힙니다.
- 사본은 **⌥+드래그로만** 움직입니다. **⌥+단발 클릭**하면 열린 슬리브 → 닫힌 슬리브 →
  레코드 판 → 열린 슬리브 순으로 형태가 바뀝니다.
- 커서를 사본 위에 올려둔 채 ⌥를 눌러도 바로 동작합니다. 사본 창은 항상 마우스
  이벤트를 받기 때문입니다. ⌥ 없이 hover하면 흰 링이 나타나지 않습니다.
- 일반 클릭·드래그·스크롤은 아무 동작도 하지 않습니다(사본 영역에서는 데스크탑
  클릭이 막힙니다).
- 사본의 중심을 화면 상단 노치 영역으로 끌어다 놓으면 삭제됩니다.
- 사본은 앱을 다시 실행해도 유지되며, 놓았던 디스플레이에 복원됩니다. 여러 스페이스에서는
  모든 스페이스에 같은 사본이 보입니다.
- 상태 메뉴의 **바탕화면 레코드 정리**로 한 번에 지울 수 있습니다.

사본은 장식물입니다. 재생/일시정지, 탐색, 곡 넘기기, 노치에 다시 꽂기는 지원하지 않습니다.

## 8. 두 손가락 스크롤의 규칙

스크롤 입력에는 마우스처럼 명확한 “놓기” 이벤트가 없습니다. 그래서 스크롤은 시간과
축을 기준으로 판단합니다.

- **축 고정** — 제스처가 시작되고 0.5pt 움직이면 가로/세로를 결정합니다. 한 번 정해진
  축은 제스처가 끝날 때까지 바뀌지 않습니다.
- **세로 우세** — 아래로 스크롤하면 열기, 위로 스크롤하면 닫기/고정 해제, 레코드가
  닫혀 있을 때는 플레이어 부르기입니다.
- **가로 우세** — 노치나 고정된 레이블 위에서는 곡 넘기기, 바이닐 위에서는 탐색입니다.
- **관성(momentum) 무시** — 손가락이 떨어진 뒤의 관성 이벤트로는 탐색하거나 넘기지
  않습니다.
- **무입력 타이머** — 고정되지 않은 레코드는 마지막 입력 후 1.4초가 지나면 들어갑니다.
- **재스크롤 고정** — 스냅 후 0.8초 이상 멈췄다가 다시 아래로 스크롤하면 고정됩니다.
  열기 스크롤을 그대로 이어서 내리는 동작은 고정으로 보지 않습니다.

## 9. 노치 없는 화면

카메라 하우징이 없는 디스플레이에서는 화면 상단 중앙의 **179pt 영역**이 노치 역할을
합니다.

- 레코드는 화면 상단 끝에서 나오고, 중심이 그 경계선에 놓입니다. 노치가 있을 때와
  같은 방식으로 아래쪽 반원만 보입니다.
- 상단 중앙에 커서를 올리면 노치가 있을 때와 같은 1px 표시가 나타납니다.
- 첫 실행 시에는 위에서 설명한 **제스처 안내 카드**가 노치 영역 아래에 나타납니다.
- 디스플레이가 여러 개면 내장 노치 디스플레이를 우선 사용하고, 노치가 없으면 현재
  주 화면(포인터/키 윈도가 있는 화면)의 상단 중앙을 사용합니다.

## 10. 피드백

| 순간 | 피드백 |
| --- | --- |
| 노치 위에 포인터 | 1px 표시, 열린 손 커서(조작 가능할 때) |
| 당김 시작 | 스크롤 시작 햅틱(`.levelChange`) |
| 40pt 스냅 | 레코드가 완전히 나옴, 햅틱 |
| 고정 완료 | 게이지가 가득 참, 햅틱 |
| 탐색 중 | 레코드 회전, 오프셋 HUD |
| 레이블 호버 | 레이블 어두워짐, 재생/일시정지 기호, 포인팅 커서 |
| 곡 넘김 | 햅틱, 새 트랙 정보 갱신 |
| 흔들어 취소 | 햅틱, 잡기 전 위치로 복귀 |
| 바탕화면 사본 생성 | 짧은 페이드 인, 햅틱 |
| 바탕화면 사본 삭제 | 상단 노치 하이라이트, 햅틱 |
| 닫기 | 스프링, 햅틱 |

재생이 시작되면 레코드는 1.2초에 걸쳐 33⅓ RPM(200°/s)까지 천천히 가속합니다. 재생이 멈추면
0.6초 동안 부드럽게 감속해 멈춥니다. 탐색이 끝나면 수동 회전에서 자동 회전으로 자연스럽게
이어집니다.

## 11. 상태별 요약

| 상태 | 사용자가 하는 일 | Umak이 하는 일 |
| --- | --- | --- |
| 닫힘(idle) | 포인터를 올림 | 1px 표시, 입력 대기 |
| 깨어남(armed) | 클릭, 스와이프, 아래로 당김, 위로 스와이프 | 클릭이면 재생 토글, 스와이프면 곡 넘김, 아래면 레코드, 위면 플레이어 호출 |
| 당김(pulling) | 아래로 드래그 | 레코드가 따라 나옴 |
| 잡힘(grabbed) | 좌우 드래그, 더 당김 | 탐색 또는 고정 게이지 |
| 탐색(scrubbing) | 좌우 이동 | 재생 위치 변경, HUD 표시 |
| 고정(pinned) | 레이블 클릭/스와이프, 닫기 | 재생 토글, 곡 넘김, 닫기 |
| 복귀(releasing) | — | 스프링으로 노치에 들어감 |

## 12. 경계와 예외

- **트랙이 없을 때** — 노치 클릭은 활성 플레이어를 앞으로 가져옵니다. 레코드를 당겨도
  탐색할 대상이 없으므로 열리지 않습니다. 스크롤도 레코드를 열지 않으며, 방향과 관계없이
  한 제스처당 한 번 플레이어를 실행하거나 앞으로 가져옵니다.
- **레코드가 닫혀 있고 트랙이 있을 때** — 위로 스와이프는 플레이어 앱을 앞으로 가져옵니다.
  재생 중이든 일시정지 상태든 같고, 레코드가 열려 있으면 이 제스처는 쓰이지 않습니다.
- **플레이어가 꺼져 있을 때** — 앱이 활성 플레이어를 실행하고, 트랙이 없으면 앞으로
  가져옵니다.
- **플레이어 선택** — 자동 모드는 재생 중인 플레이어를 우선하고, 없으면 일시정지, 트랙
  보유 순으로 고릅니다. 권한이 거부된 플레이어는 사용 가능한 후보를 밀어내지 않으며,
  설치되지 않은 플레이어는 후보에서 제외되고 메뉴에서 회색으로 표시됩니다. 메뉴의 플레이어
  하위 항목에서 Music이나 Spotify를 고정하면 나머지 서비스는 완전히 멈춥니다. 콜드 스타트
  에서는 마지막으로 실제 구동했던 플레이어만 실행하고, 기록이 없으면 아무 것도 실행하지
  않습니다. 레코드가 나와 있는 동안에는 더 나은 후보가 생겨도 전환하지 않고, 레코드가
  돌아간 뒤에 적용합니다.
- **자동화 권한이 없을 때** — 상태 메뉴 헤더에 권한 필요 상태가 표시되고, 시스템 설정의
  자동화 항목으로 안내합니다. 알림과 헤더는 현재 활성 플레이어의 이름을 사용합니다.
- **트랙 시작/끝** — 그 이상 탐색하지 않고 레코드도 더 돌지 않습니다.
- **아주 짧은 트랙** — 0.5초 이하로 보고되면 재생할 트랙이 없는 것으로 처리합니다.
- **여러 디스플레이** — 내장 노치 화면을 우선하고, 없으면 주 화면의 상단 중앙을
  사용합니다. 화면 구성이 바뀌면 오버레이를 다시 배치합니다.
- **앨범 아트 읽기/다운로드 실패** — 트랙 정보로 만든 종이 레이블로 대체합니다. Spotify의
  커버는 네트워크가 필요하며, 일시적 실패는 잠시 후 다시 시도합니다.

## 13. 구현 메모

이 문서의 수치는 다음 파일에서 조정할 수 있습니다. 전체 상수 표와 기본값은
[tuning.md](tuning.md)에 정리되어 있습니다.

| 파일 | 내용 |
| --- | --- |
| `Interaction/VinylLayout.swift` | 당김 거리, 고정 거리, 스킵 임계값, 레코드/레이블 크기 |
| `Interaction/ScrubEngine.swift` | 속도 기반 탐색 감도와 클램프 |
| `Interaction/ScrollAxisLock.swift` | 스크롤 축 고정 |
| `Interaction/ConfirmAccumulator.swift` | 고정 게이지와 속도 보정 |
| `Interaction/WiggleDetector.swift` | 흔들어 취소 판정 |
| `Interaction/OverlayController.swift` | 제스처 상태 머신, 창 전환, 타이머 |
| `Music/ScriptedMusicService.swift` | 플레이어 폴링, 가용성, 아트워크 캐시 |
| `Music/PlayerCoordinator.swift` | 자동/고정 플레이어 선택과 전환 |
| `Music/AppleMusicBridge.swift`, `Music/SpotifyBridge.swift` | 플레이어별 AppleScript |
| `UI/GestureHintView.swift` | 첫 실행 제스처 안내 카드 |
| `App/AppDelegate.swift` | 안내 카드 노출 시점과 메뉴 항목 |

첫 실행 안내를 다시 테스트하려면 `UserDefaults`의 `umak.gestureHintShown` 값을 지우고
앱을 다시 실행하거나, `--gesture-hint` 인자로 강제로 표시할 수 있습니다.

```sh
defaults delete com.umak.app umak.gestureHintShown
open build/Umak.app --args --gesture-hint
```

`--gesture-hint`는 노치가 있는 화면에서도 카드를 표시하므로 레이아웃 확인에 유용합니다.
