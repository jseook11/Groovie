# 바탕화면 레코드 (Option+드래그 복사) 설계 노트

상태: **설계 · 작업 계획** · 2026-10-22
관련 문서: [record-crate.md](record-crate.md) (크레이트/플레이리스트 방향, 후속 후보)

## 0. 한 줄 요약

노치의 레코드를 **Option(⌥)을 누른 채 클릭해 드래그하면**, 재생 중인 곡의
**장식용 사본 한 장**이 튀어나와 포인터를 따라온다. 바탕화면에 놓으면 그 자리에
레코드가 남는다. **Option을 누른 채 드래그하지 않고 한 번 클릭하면**, 같은 곡이
**앨범 커버/슬리브로 포장된 형태**로 바탕화면에 놓인다. 노치의 원본과 재생 상태는
전혀 바뀌지 않는다. 바탕화면의 사본은 **Option+드래그로만 움직일 수 있고**, 상단
노치 상호작용 영역으로 끌어다 놓으면 삭제된다.

바탕화면의 사본은 두 가지 표현을 가진다.

| 형태 | 만드는 법 | 표현 |
| --- | --- | --- |
| **레코드 판** (기본) | ⌥+클릭 **드래그** → 원하는 위치에 놓기 | 지금 노치에서 렌더하던 바이닐 한 장을 **정적 이미지**로 |
| **포장된 앨범** | ⌥+**단발 클릭** (드래그 없음) | 앨범 커버 + 안쪽 종이 슬리브에 든 레코드(정적 합성) |

두 형태 모두 **순수 장식물**이다. 회전하지 않고, 재생/탐색/곡 넘기기와 무관하며,
렌더링 이후 프레임 타이머를 돌리지 않는다. CPU 소모는 사실상 0에 수렴한다.

## 1. 범위와 원칙

### 하는 것

- Option+클릭 드래그로 현재 트랙의 **레코드 판 사본**을 만들어 바탕화면에 놓는다.
- Option+단발 클릭으로 같은 곡을 **포장된 앨범(커버 + 슬리브) 형태**로 바탕화면에
  놓는다. 드래그 없이도 “앨범을 소유”하는 경로다.
- 사본은 앱을 재실행해도 남는다(메타데이터 + 아트워크 + 위치 + 형태 저장).
- 사본을 Option+드래그로 옮긴다.
- 사본을 상단 노치 영역으로 끌어다 놓으면 삭제한다.
- 상태 메뉴에서 바탕화면 레코드를 한 번에 정리한다.

### 절대 하지 않는 것 (이번 범위)

- 사본을 클릭해 재생/일시정지, 탐색, 곡 넘기기, 닫기.
- 사본을 노치에 다시 꽂아 재생하거나 플레이리스트로 승격.
- 사본과 원본의 실시간 동기화(사본은 복사 시점의 스냅샷).
- 사본의 형태를 나중에 바꾸기(판 ↔ 포장). 만들 때 정해진 형태로 유지한다.
- Music의 라이브러리/플레이리스트/`disliked` 변경.

사본은 **순수 장식물**이다. 회전하지 않고, 재생 상태도 없다. 마우스를 올리면
Option으로 움직일 수 있다는 힌트만 조용히 보여준다.

### 문서와의 관계

`record-crate.md`는 “클릭으로 상자를 열어 모으고, 다시 꽂아 재생하는” 별도 방향이다.
이 문서는 그 방향을 대체하지 않는다. **바탕화면 장식**은 크레이트 없이도 성립하는
더 작은 v1으로 먼저 구현한다. 크레이트는 후속 후보로 남긴다.

## 2. 제스처 지도

| 입력 | 위치 | 동작 |
| --- | --- | --- |
| ⌥+클릭 드래그 | 노치의 레코드(닫힘/고정 모두) | **레코드 판** 사본을 꺼내 포인터로 운반 |
| ⌥+클릭 (이동 없음, ≤ 4pt) | 노치의 레코드/노치 영역 | **포장된 앨범**을 기본 자리에 놓기 |
| 드래그 후 놓기 | 바탕화면(어느 화면이든) | 그 자리에 레코드 판 사본 배치 |
| 드래그 후 놓기 | 상단 노치 영역 | 복사 취소(사본을 만들지 않음) |
| ⌥+클릭 드래그 | 바탕화면의 사본 | 사본 이동 |
| 놓기 | 상단 노치 영역 | 사본 삭제 |
| 일반 클릭/드래그 | 바탕화면의 사본 | 아무 동작 없음(데스크탑 클릭은 통과) |
| ⌥+단발 클릭 | 바탕화면의 사본 | 아무 동작 없음(형태 변경 없음) |
| 일반 클릭/스크롤/드래그 | 노치의 레코드 | 기존 동작 그대로 |

**Option 타이밍.** 판정은 `mouseDown` 시점의 `NSEvent.modifierFlags`로 한다.
드래그를 시작한 뒤에 Option을 눌러도 복사로 바뀌지 않는다. 우발적인 복사를 막기
위해 “누른 채로 시작”만 인정한다.

**드래그와 단발 클릭의 구분.** Option을 누른 채 `mouseUp`까지 이동이
`clickSlop`(4pt) 이하면 **포장**, `pullStartDistance`(8pt) 이상이면 **레코드 판**
드래그다. 그 사이(4~8pt)는 드래그로 인정하지 않고 포장도 하지 않는다(손떨림 보호).

**레이블 클릭과의 관계.** Option이 눌려 있으면 레이블 위에서 시작해도 재생/일시정지가
아니라 복사 후보가 된다. 기존 “레이블 클릭 = 재생 토글”은 Option 없이 누를 때만
유지한다.

**기존 제스처와의 충돌.** `handleMouseDown`의 가장 앞에서 Option을 검사하고,
복사 세션이면 기존 `pendingConfirm` / `latched` / `releasing` 분기로 내려가지 않는다.
따라서 복사 드래그가 닫기·고정·탐색·재생 토글을 건드리지 않는다.

## 3. 복사 드래그 흐름

1. `mouseDown`에 Option이 있으면 `CopyDragSession`을 만들고 기존 세션 생성은 건너뛴다.
2. 이동이 `pullStartDistance`(8pt)를 넘으면 고스트 레코드를 띄운다.
   - 닫힌 레코드: 노치 아래 경계에서 튀어나온다.
   - 고정된 레코드: 레코드 중심에서 한 장이 겹쳐 나온다.
3. 고스트는 포인터를 따라다니며, 원본 레코드/재생/회전은 그대로 둔다.
4. `mouseUp`:
   - 이동이 `clickSlop`(4pt) 이하: **포장된 앨범**을 기본 자리에 만든다(3.1).
   - 이동이 4pt 초과 8pt 미만: 아무것도 만들지 않는다(손떨림 보호).
   - 상단 노치 영역 안: 취소한다(사본을 노치로 되돌리는 짧은 흡입 연출).
   - 그 밖: 드롭 지점에 **레코드 판** 사본을 만든다.
5. `finishLostDrag`(mouse-up 유실)나 Esc는 고스트를 지우고 아무것도 만들지 않는다.

### 3.1 포장된 앨범 (Option+단발 클릭)

- 드래그 없이 Option+클릭하면, 현재 곡의 커버가 **기본 자리**에 나타난다.
- 기본 자리: 화면 상단 중앙, 삭제 존 바로 아래.
  - 중심 `x = 화면 중앙`
  - 중심 `y = screen.maxY - (notchHeight + 80) - 아이템높이/2 - 16`
  - 이미 사본이 있으면 오른쪽 아래로 24pt씩 캐스케이드하고, 화면 안으로 클램프한다.
  - 드래그로 원하는 곳으로 옮길 수 있다.
- 연출: 0.25초 동안 레코드가 슬리브 안으로 들어가는 **1회성** 애니메이션 후
  완전히 정적이 된다. 애니메이션이 끝나면 타이머/애니메이션을 남기지 않는다.
- 원본 레코드가 닫혀 있어도 된다. 노치의 검은 영역을 Option+클릭해도 “현재 앨범을
  꺼내 포장”하는 것으로 읽힌다.
- 재생 중인 트랙이 없으면 아무 일도 하지 않는다.
- 같은 곡을 여러 번 포장해도 된다(독립 사본).

### 3.2 기본 자리와 드롭 지점

- **단발 클릭(포장)**: 위의 기본 자리. 포인터 위치를 쓰지 않는다.
- **드래그(레코드 판)**: 포인터를 놓은 전역 좌표. 화면의 `visibleFrame` 안으로
  클램프한다. 여러 화면이면 포인터가 있는 화면을 쓴다.
- 두 경우 모두 사본의 중심이 삭제 존 안에 들어가지 않게 기본 배치를 보정한다.

### 고스트 창

- `CopyGhostPanel`: borderless, non-activating, transparent, `ignoresMouseEvents = true`.
- 레벨: `statusBar + 2` 수준. 다른 앱 위에서도 드래그 중에는 보여야 한다.
- `collectionBehavior`: `canJoinAllSpaces`, `fullScreenAuxiliary` (드래그 중 전체 화면
  앱 위에서도 보이도록).
- 표시 내용: `VinylDiscView`와 같은 렌더러로 만든 정적 레코드 한 장. 원본과 같은
  라벨/아트워크/스킨을 쓴다.
- 마우스 이벤트를 받지 않으므로, 드래그 이벤트는 계속 노치 패널로 들어온다.

## 4. 바탕화면 레코드 창

### 표현과 렌더링 (CPU ≈ 0)

사본은 **만들 때 한 번 렌더링한 정적 이미지**를 창에 붙이는 방식으로 그린다.
SwiftUI `@State`/`@ObservedObject`로 매 프레임 다시 그리지 않고, 회전·호버 애니메이션·
프레임 타이머를 두지 않는다. 창이 살아 있는 동안 CPU를 쓰는 작업은 없다.

| 형태 | 크기(기본) | 이미지 |
| --- | --- | --- |
| `.disc` (레코드 판) | 지름 180pt | `RecordTextureRenderer`로 만든 바이닐 한 장. 지금 노치에서 보던 것과 같은 라벨/아트워크/스킨 |
| `.sleeve` (포장된 앨범) | 커버 200×200pt, 합성 270×200pt | 왼쪽에 앨범 커버, 오른쪽 뒤로 반투명 종이 슬리브와 바이닐 가장자리가 살짝 보이는 합성 이미지 |

- 아트워크가 있으면 커버는 아트워크를 정사각형으로 채운다.
- 아트워크가 없으면 `RecordTexture`의 생성 레이블과 같은 팔레트/타이포로
  **생성 커버**를 만든다(제목·아티스트·`SIDE A`·`33⅓ RPM`).
- 2x 백킹 기준으로 렌더링해 Retina에서도 선명하게 한다.
- 스킨을 바꾸면 모든 사본을 **한 번만** 다시 렌더링한다. 그 외에는 이미지가
  바뀌지 않는다.
- 아트워크 파일은 복사 시점 스냅샷이라 재생 중 트랙이 바뀌어도 사본은 그대로다.

### 층과 동작

- 사본 하나당 `DesktopRecordWindow` 하나. 내용은 정적 레코드.
- 창 레벨: `NSWindow.Level.desktop` 계열. **일반 앱 창 아래, 배경화면/데스크탑
  아이콘과 같은 층**에 놓여 “바탕화면 장식”으로 읽힌다.
  - 정확한 레벨(`.desktop` vs `.desktopIcon`)은 스파이크로 검증한다(9장).
- `isOpaque = false`, `backgroundColor = .clear`, `hasShadow = false`.
  그림자는 SwiftUI 콘텐츠 안에서 그려 창 밖으로 잘리지 않게 한다.
- `.nonactivatingPanel` 또는 키가 되지 않는 `NSPanel`로 포커스를 훔치지 않는다.
- 창 크기: 레코드 지름 + 그림자 여백. `acceptsFirstMouse = true`.

### Option 없을 때 클릭 통과

바탕화면 아이콘을 가리지 않도록, Option이 눌려 있지 않으면 창이 마우스 이벤트를
무시한다(`ignoresMouseEvents = true`). Option이 눌린 동안만 이벤트를 받는다.

- Option 상태는 **포인터가 사본 근처에 있을 때만** 짧게 폴링한다
  (`CGEventSource.flagsState(.combinedSessionState)`, 약 15Hz). 접근성 권한이 필요 없다.
  - 전역 `mouseMoved` 모니터(이벤트 구동)로 포인터가 사본 반경 + 여유 안에 있는지
    판단한다. 근처에 없으면 타이머를 멈춘다 → 유휴 시 CPU ≈ 0.
  - 이 근접 폴링이 “포인터를 멈춘 채 Option만 누른 뒤 클릭”하는 경우도 잡아준다.
- 드래그 중에는 Option을 떼도 이벤트를 계속 받는다.
- 이 동작이 불안정하면 1차 구현에서는 “창 안 클릭을 삼킨다”로 두고, 클릭 통과는
  후속 폴리시로 미룬다. (작은 사각형 하나가 데스크탑 클릭을 막는 정도)

### 호버/이동 피드백

- Option이 눌린 상태에서 포인터가 사본 위에 오면: 커서 `openHand`, 레코드 가장자리에
  얇은 링, 살짝 떠오르는 그림자.
- Option+드래그 중: 커서 `closedHand`, 창 레벨을 일시적으로 `statusBar + 2`로 올려
  다른 앱 위에서도 사본이 보이게 한다. 놓으면 데스크탑 레벨로 되돌린다.
- 이동은 포인터 델타에 1:1로 따라간다. 관성/스냅 없음.
- 놓을 때 화면 밖으로 나가지 않게 클램프한다.

## 5. 삭제(정리)

- **삭제 존**: 화면 상단 중앙, 노치를 감싸는 영역.
  - `x`: 노치 중심 기준 `max(notchWidth + 160, 320)` 폭
  - `y`: 화면 맨 위부터 `notchHeight + 80` 높이
  - 노치가 없는 화면도 같은 규칙(상단 중앙).
- 바탕화면 사본을 드래그하는 동안 포인터가 삭제 존에 들어오면:
  - 노치 쪽에 옅은 “놓아서 정리” 하이라이트를 띄운다(별도 얇은 패널 또는 기존
    노치 큐 재사용).
  - 사본은 살짝 어두워지고 크기가 줄어 “빨려 들어갈 준비”를 보여준다.
- 놓으면: 노치로 빨려 들어가는 0.18초 연출 → 창 닫기 → 저장소에서 제거 → 햅틱.
- 삭제는 되돌릴 수 없지만, 같은 곡을 다시 Option+드래그하면 되므로 확인 창은
  띄우지 않는다.
- 여러 장을 한 번에 지우려면 상태 메뉴의 **바탕화면 레코드 정리**를 쓴다(확인 있음).

## 6. 데이터 모델과 저장

```swift
struct DesktopRecord: Codable, Identifiable {
    let id: UUID
    let track: TrackSnapshot
    let style: DesktopRecordStyle   // .disc | .sleeve
    var position: CGPoint           // 화면 전역 좌표, 아이템 중심
    var screenID: String?           // CGDirectDisplayID 문자열
    let createdAt: Date
}

enum DesktopRecordStyle: String, Codable {
    case disc       // ⌥+드래그로 만든 정적 레코드 판
    case sleeve     // ⌥+단발 클릭으로 만든 포장된 앨범
}

struct TrackSnapshot: Codable {
    let persistentID: String    // NowPlaying.trackID
    let title: String
    let artist: String
    let album: String
    let duration: Double
    var artworkFile: String?    // artwork/ 안의 상대 파일명
}
```

- `.sleeve`의 합성 이미지는 저장하지 않고, 저장된 메타데이터 + 아트워크로 시작할 때
  다시 렌더링한다(파일 수를 줄이고 스킨 변경도 반영).
- `.disc`와 `.sleeve`는 같은 사본 모델을 공유하고 `style`만 다르다. 이동/삭제/저장
  규칙은 동일하다.

- 저장 위치: `~/Library/Application Support/Groovie/desktop-records.json`
  - 아트워크: 같은 폴더의 `artwork/<recordID>.png` (최대 512px, PNG)
- 최상위에 `version`을 두어 마이그레이션 여지를 남긴다.
- 쓰기는 원자적(`Data.write(options: .atomic)`). 드래그 중에는 저장하지 않고
  **놓을 때 한 번만** 저장한다. 생성/삭제는 즉시 저장.
- 손상된 JSON: 원본을 `desktop-records.corrupt-<timestamp>.json`으로 옮기고 빈
  목록으로 시작한다.
- 아트워크가 없거나 읽기에 실패하면 `RecordTexture`의 생성 레이블로 대체한다
  (제목/아티스트 기반). 아트워크 파일이 사라져도 레코드는 보인다.
- 같은 곡을 여러 번 복사해도 된다. 각 사본은 독립 UUID를 가진다.
- 안전 상한: 100장. 넘으면 새 복사를 거부하고 메뉴에 안내한다(런어웨이 방지).

### 화면/위치 복원

- 저장된 `screenID`가 있으면 그 화면을 찾는다.
- 화면이 사라졌으면 주 화면으로 옮기고 `visibleFrame` 안으로 클램프한다.
- 화면 구성 변경 알림(`didChangeScreenParametersNotification`)에서 모든 사본을
  다시 클램프한다.
- 레코드 중심이 화면 밖으로 완전히 나가지 않게, 최소 지름의 절반은 화면 안에
  남긴다.

## 8. 구현 순서

1. **데이터 계층** — 모델(`style` 포함), 저장소, 아트워크 캐시, 커버/레코드 렌더러,
   클램프/삭제 존/기본 자리 순수 함수, `SelfChecks`. UI 없이 `make test` 통과.
2. **바탕화면 사본 창** — 저장된 사본을 데스크탑 레벨에 정적 이미지로 띄우고,
   재실행 후 복원. `.disc`와 `.sleeve` 두 표현. 앱 시작/종료, 화면 변경, 스킨 변경
   시 1회 재렌더링. 메뉴의 “모두 정리”.
3. **노치에서 복사/포장** — modifier 전달, Option 최우선 분기, 복사 세션, 고스트 패널,
   드래그 드롭 시 레코드 판 생성, **단발 클릭 시 포장된 앨범 생성**, 노치 드롭 시 취소.
4. **바탕화면 사본 조작** — Option+드래그 이동, 드래그 중 레벨 상승, 삭제 존
   하이라이트와 삭제, 화면 경계 클램프.
5. **폴리시** — Option 없을 때 클릭 통과, 호버 힌트, 포장 1회성 애니메이션,
   로컬라이제이션, 데모, 문서(ux-guide/README), 수동 QA, CPU 유휴 측정.

**스파이크(구현 전 0.5일 권장):** `NSWindow`를 데스크탑 레벨에 띄웠을 때
① Finder 아이콘과의 순서, ② 클릭 수신 여부, ③ 전체 화면/스페이스 전환에서의
표시, ④ `CGEventSource.flagsState` 기반 Option 감지. 이 네 가지가 4장 설계의
전제다. 결과에 따라 “항상 위 장식” 또는 “클릭 삼킴”으로 대체한다.

## 9. 열린 결정 (기본안 표시)

1. **층**: 데스크탑 레벨(기본, 요청대로 “바탕화면”) vs 항상 위. 스파이크 결과에
   따라 조정.
2. **회전**: 두 형태 모두 완전 정적(기본). 재생으로 오해될 여지를 없앤다.
3. **Option 없을 때 클릭**: 데스크탑으로 통과(기본) vs 창 안 클릭 삼킴(폴백).
4. **복사 소스**: 닫힌 노치와 고정된 레코드 모두(기본) vs 고정된 레코드만.
5. **드롭 위치**: 앱 창 위에 놓아도 그 전역 좌표에 사본 생성(기본). 앱 창에
   가려져도 바탕화면을 보면 있다.
6. **중복**: 같은 곡 여러 장 허용(기본). 최대 100장.
7. **삭제 확인**: 드래그 삭제는 확인 없음(기본), 메뉴 일괄 정리는 확인 있음.
8. **크레이트 문서**: 후속 후보로 유지(기본).
9. **포장 형태**: 커버만 vs **커버 + 안쪽 슬리브/바이닐 살짝 보임**(기본, 첨부
   이미지 참고). 합성 비율은 시안에서 확정.
10. **포장 기본 위치**: 화면 상단 중앙 캐스케이드(기본) vs 화면 중앙 vs 포인터.
11. **포장 연출**: 0.25초 1회성 삽입 애니메이션(기본) vs 즉시 표시. 어느 쪽이든
    끝난 뒤에는 정적.

## 10. 테스트와 QA

### 자동 (`make test`)

- `DesktopRecord` JSON 왕복(`style`, 아트워크 경로 포함), 버전 필드.
- 손상 JSON → 빈 목록 복구.
- 위치 클램프: 화면 안/밖, 화면 ID 없음/사라짐.
- 기본 자리 계산: 삭제 존과 겹치지 않음, 캐스케이드 후 화면 안.
- 삭제 존: 노치 중앙은 포함, 화면 중앙/하단은 제외.
- 복사 판정: Option+이동 ≥ 8pt = 레코드 판, Option+단발 클릭 = 포장,
  Option 없음 = 기존 pull, 4~8pt = 취소.
- 중복 복사 시 UUID가 서로 다른지, 같은 곡의 `.disc`/`.sleeve`가 공존하는지.
- 커버 렌더러: 아트워크 있음/없음 모두 정사각형 이미지를 만들고, 생성 커버가
  제목/아티스트를 포함하는지.

### 수동

- 노치 레코드(닫힘/고정)에서 ⌥+드래그 → 바탕화면에 **레코드 판** 배치.
  원본 재생/회전/위치 불변.
- 노치에서 ⌥+단발 클릭 → **포장된 앨범**이 기본 자리에 나타나고, 0.25초 뒤 정적.
- ⌥+클릭만 했을 때 재생이 토글되지 않는지, 4~8pt 손떨림으로 사본이 생기지 않는지.
- 사본을 ⌥+드래그로 이동, 재실행 후 위치/형태 유지.
- 사본을 상단 노치로 끌어 삭제, 저장소에서도 제거.
- 일반 클릭/더블클릭이 사본을 통과해 Finder 아이콘에 닿는지(4장 폴리시).
- 앱 창 아래에 가려지는지(데스크탑 레벨), 전체 화면 앱에서는 보이지 않는지.
- 여러 디스플레이: 다른 화면에 놓기, 화면 분리 후 재실행.
- Music 꺼짐/트랙 없음/아트워크 없음 상태에서 복사·포장·복원.
- 앱 비활성화 → 활성화 시 사본 복귀.
- 메뉴 “바탕화면 레코드 정리” 확인/취소.
- 유휴 상태(사본만 떠 있음)에서 CPU가 0에 가까운지, Activity Monitor로 확인.
